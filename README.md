# Breakpad

Finger-drumming drum and bass instrument. Two 4x4 pad banks (drums, break chops + FX) over a live backing track
(chords, bass, atmosphere) in nine styles: Liquid, Jungle 94, Neurofunk, Atmospheric, Jump Up, Halftime, Rollers,
Darkstep and Hardcore 92. Runs in the browser; the Mac app adds the trackpad as an 8x4 multi-touch pad surface and
pads on the Touch Bar.

## Play

- Left hand pads: `1 2 3 4 / Q W E R / A S D F / Z X C V` (drums)
- Right hand pads: `7 8 9 0 / U I O P / J K L ; / M , . /` (break chops, vocals, FX)
- `Space` start/stop backing, `Left/Right` kit, `Up/Down` held = filter, `Enter` breakdown/drop on the next bar
- Hold `Shift` for 1/16 rolls, `Option` for 1/32 rolls
- `T Y G H` chords, bass, atmosphere, guide percussion, `5 6` tempo
- Two-finger scroll = DJ filter
- Mac app: `Tab` turns the trackpad into pads (8 columns x 4 rows, left half drums, right half break + FX)

## Run

- Web: serve the folder (`python3 -m http.server`) and open `index.html`.
- Mac: `Mac/build.sh install` builds `Breakpad.app` with the web app inside and copies it to `/Applications`.
